# Blockchain and its Applications Practical File | University of Delhi (DU)

Welcome to the repository for the **Blockchain and its Applications** practical file! This repository contains the complete Jupyter Notebook implementation of the practical questions assigned for final-year BSc Computer Science students at the **University of Delhi (DU)**.

If you are a student searching for **"blockchain and its application practical question"** or looking for the official DU syllabus practical implementations, this repository serves as your complete guide and reference.

## 📚 About This Repository
This practical file (`Blockchain.ipynb`) is designed to provide hands-on experience with cryptographic algorithms, blockchain architecture, smart contracts, and permissioned networks. The code is written primarily in Python and Solidity, and is formatted so it can be executed easily using platforms like Google Colab or Jupyter Notebook.

## 📝 Practical Questions Index

Below is the complete list of practical questions covered in this repository. These align with the standard curriculum for the University of Delhi's final year Computer Science program:

1. **Question 1:** Using SHA256, obtain the message digest to string "Blockchain Developer".
2. **Question 2:** WAP (Write a Program) to encrypt and decrypt the message "Hello World" using SHA256.
3. **Question 3:** Implement RSA cryptographic algorithm.
4. **Question 4:** Create a simple blockchain using proof of work (PoW).
5. **Question 5:** Demonstrate sending of a digitally signed document.
6. **Question 6:** Create a BlockChain block containing block hash, transaction history, time of creation.
7. **Question 7:** Create a blockchain having 5 nodes and print the hash value of each node.
8. **Question 8:** Create a blockchain of 5 nodes and check its validity.
9. **Question 9:** Implement a smart contract using solidity programming language.
10. **Question 10:** Create a simple permissioned blockchain using Hyperledger fabric.

## 🛠️ Tools & Technologies Used
* **Python:** Used for hashing, cryptographic algorithms, and building the core blockchain data structures.
* **Libraries:** `hashlib`, `pycryptodome` (for RSA and digital signatures), `time`, `json`.
* **Solidity:** Used for writing and deploying the basic smart contract (`SimpleStorage.sol`).
* **Hyperledger Fabric (Simulation):** A Python implementation used to demonstrate permissioned blockchain logic and access control lists.
